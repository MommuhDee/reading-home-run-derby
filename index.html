How to play & home-screen setup

Set each child's level independently. Choose a hit, help them read the displayed word or sentence, then tap “Read it! Hit the ball.” The app advances runners and scores runs automatically. Record outs for missed swings or optional baseball challenges, not for reading mistakes. Three outs switches sides. Switch sides manually at any time.

For an Android home-screen icon, host these game files on a secure website (such as GitHub Pages), open that website in Chrome, then use the browser menu → Add to Home screen or Install app. Opening this HTML file directly may work for playing, but reliable installation and offline support require hosting. Scores are saved in this browser on this device, not synchronized between devices.

Progress and game state are stored locally. Use Download scores for a backup. Clearing site data may erase saved scores.
